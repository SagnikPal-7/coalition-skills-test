# Tech.Care Patient Dashboard

Front-end skills test implementation based on the provided Adobe XD design and Coalition Technologies Patient Data API.

## Features

- React and Vite
- Responsive single-page dashboard
- Patient Data API integration
- Jessica Taylor patient profile
- Diagnosis history
- Blood pressure visualization
- Respiratory rate, temperature, and heart rate
- Diagnostic list
- Lab results
- Chart.js and react-chartjs-2
